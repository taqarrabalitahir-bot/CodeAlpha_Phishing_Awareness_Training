# CodeAlpha_PhishingAwarenessTraining

**CodeAlpha Cyber Security Internship | Task 2: Phishing Awareness Training**

An online training module (plus PDF slides and a Word handout) that teaches people how to recognize, resist and report phishing attacks.

## What it covers
| Task requirement | Where in the module |
|---|---|
| Recognize phishing emails | 8 red flags, annotated mock email (tap the numbers), SLAM method |
| Recognize fake websites | Domain reading rules, padlock myth, real vs fake URL table, safe verification habits |
| Social engineering tactics | 8 psychological triggers, tactics table (pretexting, baiting, quid pro quo, tailgating, vishing, MFA fatigue) |
| Best practices and tips | Personal habits, organizational controls, incident response ("I clicked, now what?"), reporting |
| Real-world examples | Google/Facebook invoice fraud, Ubiquiti, RSA, Podesta, Twitter 2020, Uber 2022, common local scam patterns |
| Interactive quizzes | 10-question scenario quiz with instant feedback and a scored result (`index.html`); printable version and answer key in the PDF/Word files |

## Files
- `index.html`: interactive online module (single file, no dependencies). Open in any browser.
- `docs/Phishing_Awareness_Training_Slides.pdf`: 30-slide presentation.
- `docs/Phishing_Awareness_Training_Module.docx`: Word version with facilitator guide (timings and activities).

## Run it
Open `index.html` locally, or host it free with **GitHub Pages**: Settings > Pages > Deploy from branch > `main` / root.

## Notes
- Example domains use the reserved `.example` suffix and documentation IP ranges, so nothing points to a real site.
- Case studies are summarized from public reporting; verify details before citing them formally.
